ABOUT SMARTCAMPUS

Making Campus Life Better

Our Project

SmartCampus is a student feedback web application designed to provide a simple way to share opinions about teaching, infrastructure, laboratories, library services, and other campus facilities.

The application presents submitted feedback and basic statistics through a user-friendly interface. It demonstrates how web technologies can support continuous improvement in an educational environment.

🎯 Our Objective

Make it easy for students to share their experiences and suggestions about campus services.

🌟 Our Vision

Encourage a campus culture where student opinions contribute to better learning experiences.

💡 Our Approach

Provide feedback forms, searchable feedback cards, and simple analytics in one application.

Technology Behind the Project

Frontend: HTML, CSS, JavaScript

Web Server: Nginx

Containerization: Docker

Automation: Jenkins CI/CD pipeline

This demonstration stores feedback in browser localStorage. A production system would require a backend, database, authentication, and appropriate access controls.
